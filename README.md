# QuickBlog

## Project Documentation

QuickBlog is an AI-powered blogging platform that enables users to create, manage, and publish blogs effortlessly.

### Features
- AI-generated content suggestions
- Customizable themes and layouts
- Built-in SEO optimization

## Setup Instructions

1. **Clone the repository:**  
   ```bash
   git clone https://github.com/UtkarshaSharma24/QuickBlog.git
   cd QuickBlog
   ```

2. **Install dependencies:**  
   Make sure you have Node.js installed, then run:  
   ```bash
   npm install
   ```

3. **Start the application:**  
   ```bash
   npm start
   ```

4. **Visit the app in your browser:**  
   Open `http://localhost:3000` to see the application in action.
